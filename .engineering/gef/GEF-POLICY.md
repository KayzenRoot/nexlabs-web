# NexLabs Web GEF Policy

1. Canonical Git and Project Brain sources outrank chat memory and derived caches.
2. Product work requires an admitted Work Order.
3. Every Work Order binds an execution base and expected evidence.
4. Context Locks become stale when material authority or base changes.
5. Deterministic proof precedes inference when practical.
6. HIGH and CRITICAL known defects block promotion.
7. Evidence binds the exact candidate/head.
8. Checkpoint promotion follows independent audit.
9. Scope discoveries are classified before admission.
10. Destructive Git/history operations require explicit authorization.

HIVE is the preferred local-first intelligence layer, not canonical write authority. Missing HIVE evidence remains UNKNOWN and fails closed for HIVE-required Work Orders.
