# NexLabs Web GEF Evidence Specification

Every promoted evidence bundle identifies:

- Work Order and Context Lock ids;
- authorized base SHA and candidate/head SHA;
- planning, GEF and HIVE exact release commits;
- HIVE availability, project resolution, Git head, index and corpus state;
- canonical sources and context retrieval boundary;
- changed files and deterministic validation commands;
- hosted workflow/run identities and ruleset snapshot;
- failures, repairs, deviations and unresolved risks;
- audit verdict and proposed checkpoint delta.

Historical evidence is reusable only while every relevant exact-state dependency remains unchanged.
