# NexLabs Web GEF Execution Protocol

Every Work Order contains OBJECTIVE, HIVE PREFLIGHT, CANONICAL BASIS, CONTEXT BUDGET, RISK / ASSURANCE, SCOPE, OUT OF SCOPE, FILES / SEAMS, REQUIREMENTS, ARCHITECTURE RULES, CONSTRAINTS, ACCEPTANCE CRITERIA, TESTS, EVIDENCE, DELIVERABLES, REVIEW FORMAT PT-BR and STOP CONDITION.

Resolve Git state first, use HIVE progressively, execute only admitted scope, collect exact-head evidence and stop at the Work Order boundary. Repair the smallest invalidated node and its dependents.
