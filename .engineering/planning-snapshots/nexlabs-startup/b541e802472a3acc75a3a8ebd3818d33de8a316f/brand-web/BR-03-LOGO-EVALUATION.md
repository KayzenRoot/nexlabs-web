# BR-03 — Logo Concept Evaluation Protocol

Status: PLANNED

## Visual prototype batch
When execution begins, generate controlled variants rather than hundreds of random marks.

For each shortlisted family:
- 3 structural variants;
- each variant in canonical monochrome;
- 16/24/32/64/128 px raster previews;
- symbol-only;
- symbol + NexLabs;
- dark/light background;
- one simple 3D projection proof.

Target initial batch: 9 serious 2D candidates, not prompt-spam.

## Evaluation dimensions
Each candidate is documented against:
- silhouette distinctiveness;
- small-size survival;
- NexLabs relevance;
- infrastructure/system semantics;
- 2D↔3D coherence;
- wordmark compatibility;
- motion potential;
- production simplicity;
- accessibility/color independence;
- apparent similarity risk.

Do not convert these dimensions into a single fake-precision score. Record strengths, weaknesses and elimination reasons.

## Elimination rounds
Round A — Geometry
Reject weak silhouettes and small-size failures.

Round B — Identity
Reject generic or competitor-adjacent marks.

Round C — System
Test wordmark, favicon, motion and 3D projection.

Round D — Brand fit
Place finalists inside actual homepage hero/header/footer mocks.

Round E — Production
Validate SVG cleanliness, Blender construction feasibility and web performance.

## Final evidence bundle
- master SVG;
- normalized viewBox;
- monochrome exports;
- responsive variants;
- favicon family;
- wordmark lockups;
- construction diagram;
- canonical 3D projection reference;
- Blender source reference;
- animation reference;
- usage/misuse rules;
- originality/similarity research notes.

## Decision rule
No logo is selected from an isolated logo sheet. Finalists must be evaluated inside the actual NexLabs visual system and institutional website context.
