## Problem
Headline:
**A long project should not have to start from zero every time context changes.**

Body:
AI-assisted development can span repositories, documents, decisions, prompts, checkpoints and execution history. HIVE is designed to organize that information into persistent project context that can be retrieved progressively and reused deliberately.

## Capability groups
Persistent project context
Maintain durable project state beyond a single model interaction.

Hybrid retrieval
Combine retrieval methods to surface relevant project information.

Progressive context
Expose context at useful levels rather than loading everything at once.

Efficiency mechanisms
Reduce repeated context transfer through structured context management and caching/delta strategies where applicable.

Governed execution
Separate context assistance from uncontrolled system action through explicit governance boundaries.

Observability
Expose system activity and operational state through telemetry/control surfaces.
