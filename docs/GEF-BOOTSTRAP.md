# GEF Bootstrap in NexLabs Web

NexLabs Web pins GEF Bootstrap v1.0.0 at `866fe3af8cccc65c929aaf6a47a924401fa448b3` as an external source workspace. It is not a published global npm CLI and is not vendored into this repository.

## Materialized surfaces

- canonical Project Brain under `docs/project-brain/`;
- domain-specific Source Hierarchy;
- GEF adoption, baseline, current, profile and source bridge records;
- Work Order, Context Lock, evidence, ledger and gate namespaces;
- deterministic governance validator;
- HIVE-first executor contract and MCP configuration;
- GitHub Governance workflow and protected-main target documentation.

The upstream release can be independently validated in its own checkout with `npm ci` and `npm run validate`. Website product dependencies do not include GEF packages.
