# 10 - Security and Governance

The website has no runtime secrets, database, authentication, analytics or third-party browser script. The static CSP remains same-origin with the existing narrowly documented inline theme bootstrap. GitHub workflows use read-only repository permissions and pinned action commits.

GEF governance fails closed for absent required files, stale Context Locks, exact-head mismatch, absolute machine paths, placeholder governance records, missing pins, missing HIVE evidence and HIGH/CRITICAL findings.

HIVE is local-first and mounted read-only below its configured project root. The MCP surface exposes only read-only project, context, memory and checkpoint tools. Provider credentials are not committed.
