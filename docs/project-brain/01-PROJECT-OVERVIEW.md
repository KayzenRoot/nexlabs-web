# 01 - Project Overview

## Identity

NexLabs Technology is a pre-incorporation technology initiative based in Brazil with global market intent. The repository is `KayzenRoot/nexlabs-web`; the public technical starting point is HIVE.

## Mission

Build a credible, static-first institutional web system for infrastructure for AI-native software while keeping claims, identity and future visual assets governed.

## Current product state

CP-01, CP-01R and CP-01F foundation work is approved on `main`. CP-02 adds the provisional token/design-system shell. CP-02R repairs the CP-02 candidate and installs the GEF/HIVE project governance layer.

## Truth boundaries

Founder identity, public email, production domain, analytics, backend, authentication, database and final brand/3D assets are not approved facts in this project state.
