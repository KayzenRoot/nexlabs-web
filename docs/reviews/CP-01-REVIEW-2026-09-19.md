## Repair findings

### R-02 — start script conflicts with static export
Severity: MEDIUM
Status: OPEN

package.json currently defines:
`"start": "next start"`

The project uses:
`output: "export"`

The production-like local serve command should use the repository static server or another appropriate static serving path rather than implying a Next.js server runtime.

Required:
Replace/document the start/serve contract consistently and test it.

### R-03 — non-indexable robots behavior should explicitly block crawl
Severity: MEDIUM
Status: OPEN

Metadata correctly emits noindex/nofollow for non-production environments, but robots.ts uses an empty allow list when non-indexable.

Required:
Make preview/local robots output explicitly disallow `/` and add a deterministic test.
