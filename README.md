# NexLabs Web

Static-first institutional web foundation for **NexLabs Technology**.

Repository: `KayzenRoot/nexlabs-web`  
Planning source: `KayzenRoot/nexlabs-startup`

CP-01 intentionally stops at an engineering foundation. It provides a semantic placeholder shell, typed content/environment/metadata contracts, tests, validation scripts, CI and a Cloudflare Workers + Static Assets configuration. It does not select the final logo or visual system, publish founder/contact details, add a backend, purchase a domain or deploy production.

## Quick start

```bash
npm ci
npm run dev
```

Run the complete local gate:

```bash
npm run check
```

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for the current contract.
